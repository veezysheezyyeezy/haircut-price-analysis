# Haircut Price Analysis

This project contains a Python script that analyzes haircut pricing data for several hairstyles.

## Files
- `haircut_analysis.py` — calculates average price, updated discounted prices, total weekly revenue, average daily revenue, and hairstyle names under a discounted threshold.

## How to run
```bash
python haircut_analysis.py
```

## Example output
```text
Average Haircut Price: 31.25
Updated Prices After $5 Discount: [25, 20, 35, 15, 15, 30, 45, 30]
Total Revenue from Last Week: 820
Average Daily Revenue: 117.14
Haircuts Under $30 After Discount: ['bouffant', 'pixie', 'crew', 'bowl', 'bob']
```
